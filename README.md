
# Getting Started

## Install Homebrew

`/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"`

## Install binaries

`brew install git bat eza nvim yazi zoxide fzf go`
`brew install --cask ghostty firefox iina puremac`

## Setup the env

- Clone the repo.
- Run `setup.sh`
- Install [Rust toolchain](https://rust-lang.org/tools/install/)
- Install [Nerdfont](https://www.nerdfonts.com/)
